# Design direction

A calm, precise document workbench: warm white canvas, a muted olive navigation rail, restrained forest-green actions, and amber review signals. Geist is served locally and paired with Geist Mono for code and numeric output.

The information hierarchy follows the improvement loop: inspect a document, define expected values, evaluate a fixed benchmark, try a candidate, and review uncertain fields. Model choice is configuration, not product identity.

The source and the extraction stay adjacent. Confidence and evidence are visible on every field; unavailable citations and missing expected values remain explicit. Saved run feedback is separate from original extraction output and ground-truth revisions.

The overview provides orientation. The workbench supports focused inspection. Tables make experiment tradeoffs comparable. A dedicated manual hill-climbing view keeps the hypothesis and the benchmark visible together.

All product UI was authored in this new repository. Extend’s open-source viewers and upload primitives were installed afresh from its official registry.
